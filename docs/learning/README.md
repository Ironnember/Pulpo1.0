## Learning checkpoints

1. Record *purpose* and the exact inputs before writing code.
2. Distinguish externally observed facts from untrusted descriptions and guesses.
3. Write negative tests for invalid numbers, substitutions, replay, unknown observation and cumulative limits.
4. Track the source URL and coverage status of each claimed learning.
5. Preserve `intelligence proposes / governance disposes / execution obeys / evidence reports`.
6. Never interpret a learning exercise, GitHub CI green check, downloaded Skill, model memory, or signed text as authorization.

## Reading and licensing

The index links to sources; it does **not** redistribute entire copyrighted books. Publisher summaries and excerpts are covered as *partial* reading. Book-cover photographs prove only that a title is visible, not ownership of the text or verified reading. For user-provided licensed books, track receipt and rights before processing; use original, short analytical notes rather than posting underlying text publicly.
