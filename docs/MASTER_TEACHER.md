# Master Teacher and Index Guide

## Canonical origin

This is the executable foundation for the learning doctrine established on
August 25, 2026. It generalizes the BBA Accounting Socratic Tutor principles
into Pulpo's knowledge architecture and is the canonical beginning of the
Master Teacher and Index Guide.

The doctrine is:

> Knowledge is not mastered because it was stored or summarized. It is
> mastered when its source, meaning, mechanism, boundaries, relationships,
> application, and teachability can all be demonstrated.

## Responsibilities

The Master Teacher and Index Guide turns sourced information into connected,
testable understanding that can be explained, applied, challenged, taught, and
retrieved later with provenance and scope intact.

- Agents perform bounded reasoning and study work.
- The Master Teacher develops and tests understanding.
- The Index Guide structures claims, relationships, evidence, confidence,
  contradictions, and reuse scope.
- The Directive Agent protects Austin-authorized intent and detects drift.
- Great Halls preserves sourced, related, confidence-calibrated memory.
- Pulpo governs consequential action and records evidence.

Learning never grants authority. A lesson or memory revision is a proposal.
Any consequential use still requires the existing canonical Pulpo policy,
approval, permit, consumption, and audit path.

## Learning loop

1. **Frame:** identify learner, objective, context, stakes, and prior model.
2. **Source:** preserve evidence, provenance, dates, versions, and source class.
3. **Structure:** connect concepts, claims, relationships, constraints, and questions.
4. **Diagnose:** locate the earliest incorrect or missing reasoning step.
5. **Explain:** show the mechanism, full mechanics, effects, and boundaries.
6. **Apply:** use the idea in a related but meaningfully new situation.
7. **Test:** use retrieval, prediction, correction, comparison, or counterexample.
8. **Teach back:** require mechanism, example, boundary, and failure mode.
9. **Record:** propose an evidence-backed, scoped memory update.
10. **Revisit:** revise confidence when evidence changes and preserve why.

## Semantic grammar

Great Halls retains the consequential-memory grammar:

> Who authorized what → outcome → constraints → evidence → confidence → reusable scope.

The learning extension is:

> What is claimed → where it came from → what it means → how it works → what
> it connects to → where it fails → how it was tested → whether it can be
> applied and taught.

Both grammars remain necessary. Learning context cannot replace authorization
context.

## Executable contracts

`pulpo.learning` adds immutable, dependency-free contracts for:

- source classification and provenance;
- evidence references instead of caller-controlled verification booleans;
- scoped knowledge units that distinguish fact, interpretation, inference,
  and authorized directive;
- complete explanation frames;
- first-root-error diagnosis;
- a Socratic answer gate that does not obstruct direct or safety-critical help;
- evidence by understanding dimension without an invented composite score;
- memory-update proposals whose authority effect is always `none`; and
- fail-closed assessment before learned material is referred to governance.

It deliberately does not add a model, agent router, persistence backend,
retrieval engine, evidence ledger, approval mechanism, or execution path.

## Understanding standard

Full understanding requires evidence for every applicable dimension:

- recall;
- meaning;
- mechanism;
- structure;
- application;
- boundary;
- diagnosis;
- teaching;
- evidence; and
- retention.

Partial mastery remains visible by dimension. The implementation does not
collapse these dimensions into a fabricated score.

## Fail-closed boundary

Consequential use is denied when essential memory is untrusted, a material
contradiction remains present, or the knowledge has not been verified. A
contradiction is cleared only by proposing a revised knowledge unit with its
new evidence and supersession reason; there is no caller-controlled
"contradictions resolved" switch. Even
verified learning produces only `refer_to_governance`; it never produces
`allow`, a permit, or an authority change.

## Proven by this change

The tests prove the local schema and decision invariants above. They do not
prove a desktop Directive Agent runtime, live source retrieval, durable Great
Halls storage, independent verification, adaptive model behavior, long-term
retention, or production teaching quality. Those require later integrations
and evidence behind the same contracts.
