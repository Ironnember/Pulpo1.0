# Pulpo Proof Zero

Status: executable foundation

## Thesis

Proof Zero treats Pulpo's own creation as the first bounded Great Halls corpus. The case study asks whether a human principal can coordinate machine capability toward a technical objective while progressively preserving explicit authority, policy, budget, execution, evidence, and learning boundaries.

Human purpose remains upstream. Machine capability remains bounded. Knowledge may inform governance but cannot manufacture authority.

## Evidence vocabulary

Every durable case-study claim MUST be classified as exactly one of:

- **verified** — reproduced or supported by independently resolvable evidence;
- **recorded** — present in dated project records but not reproduced in the current proof context;
- **inferred** — reasoned from evidence but not mechanically established;
- **proposed** — a target, hypothesis, design, or societal thesis;
- **blocked** — prevented by a named missing control or proof.

A renderer MUST NOT upgrade a claim merely because it is persuasive or useful to a recipient.

## Architecture boundary

`pulpo.proof-zero.v1` is a read-only projection over existing Pulpo evidence references. It is not a second ledger, router, authority plane, memory authority, approval service, or permit issuer.

Proof Zero entries may describe intent, identity and authority, policy, budget, permits, execution, evidence, human decisions, outcomes, contradictions, and remaining gaps. They must resolve those descriptions to existing evidence references when claiming verified or recorded status.

Only verified entries are eligible to be referred onward for consequential consideration. Eligibility is not authorization: consequential action must still pass through the canonical GovernanceKernel.

## First corpus

The first corpus should cover the canonical Pulpo1.0 development sequence and deliberately include different epistemic states:

1. executable governance and denial semantics — verified only where reproduced;
2. dated historical dogfood results — recorded until independently reproduced;
3. founder contribution and capital-compression claims — inferred unless independently measured;
4. governed agency as a new form of capital — proposed;
5. production hostile-agent containment — blocked until independent authority and host containment are proven.

## Recipient projections

The same entries may be rendered as investor, security-review, or public-founder projections. Projection changes expression, not truth status, provenance, scope, contradiction state, or authority.

## Acceptance standard

Great Halls Proof 0 succeeds when a bounded corpus can:

1. preserve source/evidence references;
2. keep verified, recorded, inferred, proposed, and blocked claims distinct;
3. preserve scope and named gaps;
4. produce multiple recipient projections without epistemic promotion;
5. preserve contradiction and supersession lineage through the learning layer;
6. survive durable restart when persistence is introduced;
7. fail closed on cross-scope retrieval when retrieval is introduced;
8. refer verified knowledge to governance without granting authority;
9. reuse the canonical Pulpo audit/evidence model rather than create a second ledger.

## Promotion path

Proof Zero is not production hostile-agent containment. The next external promotion gates remain canonical reproducibility by an outside evaluator, independently isolated human authority, enforced host containment, one real low-risk external workload, independent adversarial reproduction, and a measurable non-founder outcome.
