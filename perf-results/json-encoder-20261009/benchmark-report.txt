Method: Fresh process per sample; imports, payload/legacy-chain setup, GC and independent result validation excluded from wall/CPU; CPU measured by process_time_ns (all process threads); native Windows peak working set includes imports and untimed fixture setup; RSS end-start is memory delta. Single local process, no pool, no digest cache. Results retained until memory observation. In-memory synthetic records; no database I/O or end-to-end effect execution; OS caches not flushed. Workload order alternates per repetition.
Five repetitions per phase/workload/size; all table values are independent medians. Batch is one complete record set for serialize, audit creation and full verify; accelerator configured batch=4096, workers=0, cache=0, so hashing remains local without IPC batching. In-memory synthetic mixed payloads include Unicode, null, nested arrays, booleans and floats; serialization retains outputs and audit creation retains records through memory measurement.
CPU samples are quantized on Windows (observed 15.625 ms increments); small-case CPU differences are coarse. CPU ms/record is CPU time divided by record count. Peak RSS uses native Windows peak working set for the whole worker lifetime, including untimed fixture setup. Memory delta is end RSS minus pre-work RSS; negative deltas can reflect working-set reclamation. MB is decimal. Baseline and optimized phases were sequential; variants were not interleaved. Other applications, CPU frequency and OS caches were not controlled.
